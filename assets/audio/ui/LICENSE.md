# Interaction sound effects

Five WAV files in this folder were converted to mono, 44.1 kHz, 16-bit PCM from Kenney's
**Interface Sounds 1.0** pack:

- `ui-click.wav` from `click_002.ogg`
- `asset-select.wav` from `select_004.ogg`
- `asset-place.wav` from `drop_002.ogg`
- `asset-delete.wav` from `close_002.ogg`
- `asset-move.wav` from `tick_002.ogg`

Created and distributed by [Kenney](https://kenney.nl/assets/interface-sounds), 11 February 2020.
